# IN-0001: Complete initial vision and track deferred extensions

## Summary

Finish the operator-facing and adoption-facing work that turns the MVP into a stable, repeatable
toolkit for real consuming repos. This initiative also preserves the explicitly deferred post-MVP
research items in the tracked dogfood wiki so future agents can find them without reopening
`scratch_space/`.

## Goals

- Make the install, update, and remote-session workflow predictable for real consuming repos.
- Tighten the agent operating guidance so wiki MCP, CLI fallback, and sister-repo usage are easy to follow.
- Add lightweight adoption checks and pilot feedback loops so future rollout work is evidence-based.
- Preserve the deferred post-MVP roadmap in canonical tracked wiki records.

## Notes

### Deferred After Initial Vision

These items remain intentionally deferred post-MVP research or expansion work. They are recorded
here so future agents can discover them from the tracked wiki even if `scratch_space/` is not part
of their normal retrieval flow.

- semantic search
- embeddings
- symbol/function-level tracing
- authority-aware search ranking
- repo-local graph customization
- profile model (`standard` vs `research`)

### Scope Boundary

This initiative focuses on finishing the original adoption and operator story first. It does not
commit the repo to GitHub Actions, `HO-*` graphing, or a semantic graph layer.
