# WK-0005: Improve consuming-repo AGENTS.md and CLAUDE.md integration

## Description

Tighten the paste-ready consuming-repo `AGENTS.md` and `CLAUDE.md` guidance so future agents can
install, bootstrap, update, and operate `kb` with fewer operator clarifications. The focus is on
high-signal instructions that match the real sister-repo + MCP/CLI boundary used in production,
including the new dispatch MCP surface and reviewed-bundle handoff lifecycle.

## Acceptance Criteria

- [x] The consuming-repo snippets clearly distinguish wiki-via-MCP from dispatch-via-MCP-or-CLI and graph-via-CLI.
- [x] The snippets explain that `kb` commands run from the sibling `kb` checkout and target the consuming repo via `--dir`.
- [x] The snippets include first-time setup, day-2 update flow, and remote-session expectations.
- [x] The snippets avoid stale or contradictory assumptions about where `kb` is installed, how MCP access is restored, and how the dispatch registry upgrade is applied.
