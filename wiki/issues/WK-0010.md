# WK-0010: Implement PLN creation and bundle normalization workflow

## Description

Add the operational workflow for creating a bare `PLN-*` record and attaching a normalized bundle
to it. The first version should support the current Superpowers-generated design and execution
artifacts as importable source material, but the workflow must stay expressed in terms of generic
normalization, validation, and archival rather than a hardcoded planner-specific pipeline.

## Acceptance Criteria

- [ ] An operator can create a bare `PLN-*` record with the approved minimal record surface.
- [ ] An operator can import or normalize upstream design and execution artifacts into the canonical
      `PLN-*` bundle layout.
- [ ] The workflow validates bundle integrity, including required entrypoints and referenced
      artifact paths.
- [ ] The workflow supports marking a `PLN-*` archived when the one-time build phase is finished
      without breaking references from later `WK-*` records.
