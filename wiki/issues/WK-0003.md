# WK-0003: Harden remote-session MCP startup and client configuration guidance

## Description

Make the MCP startup model explicit and repeatable for remote development, VM-based work, and
reconnected sessions. The goal is to remove ambiguity around what persists across reboots, what the
agent client must launch, and how operators recover wiki MCP access when the stdio server is not
running.

## Acceptance Criteria

- [ ] The docs explain that `npm run wiki:mcp` starts a live stdio process rather than a persistent daemon.
- [ ] The docs explain what persists across VM reboots and what must be restarted.
- [ ] The recommended client configuration path is documented for agent tools that can launch MCP commands automatically.
- [ ] The manual fallback path is documented for sessions where automatic MCP launch is not available.

## Notes

- This work is based directly on the remote-session confusion surfaced during first consuming-repo rollout.
- This work is tracked under [IN-0001](../initiatives/IN-0001.md).
