# WK-0011: Integrate PLN with wiki retrieval and reference rules

## Description

Define and implement how `PLN-*` participates in the rest of the wiki system. The plan record
itself should be first-class and referenceable, while the operational bundle stays intentionally
out of the standard work-tracking surfaces by default. This work should also formalize how `WK-*`
records point to a plan and to stable bundle files or headings inside that plan.

## Acceptance Criteria

- [ ] `PLN-*` participates in schema linting and reference validation as a normal wiki record.
- [ ] `PLN-*` is excluded from generated backlog-style work views such as `now.md`, `backlog.md`,
      `inbox.md`, and `archive.md` unless there is an explicit design change later.
- [ ] Bundle internals stay out of default graph and search scope in the first pass, while the
      `PLN-*` record remains discoverable and linkable.
- [ ] The repo documents a stable reference convention for `WK-*` links into `PLN-*` bundle files,
      favoring file and heading links over fragile line-number references.

## Notes

- This work is tracked under [IN-0002](../initiatives/IN-0002.md).
- The authoritative feature design is [2026-05-06-pln-design.md](../../docs/superpowers/specs/2026-05-06-pln-design.md).
- The authoritative implementation plan is [2026-05-06-pln-implementation.md](../../docs/superpowers/plans/2026-05-06-pln-implementation.md).
- The goal is integration by reference, not promoting plan bundles into another canonical backlog
  surface.
