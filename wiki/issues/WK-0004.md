# WK-0004: Define private sister-repo deployment and update workflow

## Description

Document and stabilize the private sister-repo deployment story for internal client work. The
current practical model is collaborator-based access to a private `kb` repo plus a local sibling
checkout on the client machine. This work should make that flow explicit, low-friction, and easy
for future agents to follow without reopening design questions.

## Acceptance Criteria

- [ ] The README explains the local sibling-repo model and the private collaborator install/update model.
- [ ] The docs explain how updates are received in a private clone (`git pull` plus dependency refresh).
- [ ] The docs explain the tradeoff of collaborator access on a personal private repo, including the lack of read-only collaborator mode.
- [ ] The consuming-repo setup flow is documented for remote machines where the original local `kb` checkout is not available.
