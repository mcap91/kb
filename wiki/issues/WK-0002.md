# WK-0002: Add static HTML graph viewer for .graph.json

## Description

Add a lightweight static HTML viewer for the graph subsystem so operators and agents can inspect
`wiki/.graph.json` visually without requiring a separate service. This is a post-MVP enhancement;
the current MVP intentionally ships only `wiki/.graph.json` and `wiki/graph-summary.md`.

## Acceptance Criteria

- [ ] Running the viewer generation step produces a static HTML artifact from `wiki/.graph.json`.
- [ ] The viewer can render nodes and edges from existing graph output without modifying source files.
- [ ] The docs explain where the viewer artifact is written and how an operator or agent opens it.
- [ ] The feature remains deterministic and does not change the existing `.graph.json` contract.

## Notes

- The MVP design explicitly excluded browser graph visualization.
- The intended follow-on is a simple local viewer, not a hosted service or semantic graph layer.
- This work is tracked under [IN-0001](../initiatives/IN-0001.md).
