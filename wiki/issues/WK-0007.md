# WK-0007: Pilot kb in real consuming repos and capture adoption fixes

## Description

Use real consuming repos as adoption pilots and capture the fixes they reveal. The first client-side
rollout already exposed gaps around private deployment assumptions, remote-session MCP startup, and
dogfood readiness. This work item keeps that loop explicit so `kb` continues to harden against
actual usage rather than only local assumptions.

## Acceptance Criteria

- [ ] At least one real consuming repo is used to validate the install/bootstrap/update flow end to end.
- [ ] Adoption issues discovered during rollout are captured back into tracked wiki records or docs updates.
- [ ] The repo documents the current recommended rollout pattern for private internal client work.
- [ ] Dogfood feedback results in concrete operator or agent-guidance improvements rather than remaining only in chat history.
