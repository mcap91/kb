# WK-0012: Dogfood PLN on kb and document the operator workflow

## Description

Use the first working `PLN-*` implementation on `kb` itself and write the operator guidance for how
to use it. The preferred dogfood target is this exact planning effort: once the minimum feature set
exists, migrate or normalize the current design and execution material into a real `PLN-*` record
so the repo proves the model on itself instead of only describing it.

## Acceptance Criteria

- [ ] The repo uses a real `PLN-*` record and attached bundle for at least one concrete planning
      effort, ideally this feature itself.
- [ ] The docs explain when to use `PLN-*` versus `IN-*`, `WK-*`, and `HO-*`.
- [ ] The docs explain the current Superpowers adapter path while making it clear that future
      planning tools can feed the same normalized kb contract.
- [ ] Dogfood findings produce tracked follow-up work if the operator workflow is awkward or the
      bundle contract leaks planner-specific assumptions.
