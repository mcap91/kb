# WK-0006: Add adoption health checks for consuming repos

## Description

Add a lightweight adoption health-check workflow for consuming repos so operators and agents can
quickly answer “is `kb` installed correctly here?” without manually replaying the whole bootstrap
story. This can be a documented checklist, a CLI command, or a small validation workflow, but it
should stay simple and deterministic.

## Acceptance Criteria

- [ ] There is a documented or automated way to verify bootstrap state, generated views, search index, and graph outputs in a consuming repo.
- [ ] The check covers the wiki/dispatch split clearly enough that agents know what is expected from each subsystem.
- [ ] The check is safe to run in mature consuming repos and does not modify unrelated source files.
- [ ] The output is simple enough to use as an operator handoff checkpoint.
