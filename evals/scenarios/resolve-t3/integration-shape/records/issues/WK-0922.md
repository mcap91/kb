# WK-0922: Wire notifications to read user preferences from the profile service

## Objective

Notifications needs to know a user's delivery preference before it sends anything. The profile module already
computes and owns that preference, and both modules live in this repo.

## Scope

- Notifications calls into profile to read one user's delivery preference.
- No change to how profile computes or stores the preference.
- Out: any change to profile's public shape beyond the one read path notifications needs.

## Open Questions

- Should notifications reach the profile service through an MCP server or a direct import?
