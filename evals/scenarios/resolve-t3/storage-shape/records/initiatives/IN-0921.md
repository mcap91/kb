# IN-0921: Scheduler pipeline steps

## Summary

Each pipeline feeding the scheduler carries its own configuration and an ordered list of steps. This
initiative tracks the work to make the scheduler read and run that configuration correctly.

## Goals

- The scheduler runs every pipeline's steps in the order the pipeline declares.
