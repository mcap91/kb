# WK-0911: Publish the internal wiki repository to the public GitHub remote

## Objective

The team's internal engineering wiki lives in its own private git repository, separate from the main
application repo. A partner team has asked to read it directly instead of receiving periodic exports, and the
simplest way to give them that is to push the private repository to a public GitHub remote.

## Scope

- Decide whether the wiki repository is pushed to a public remote at all, before anything else here is scoped.
- Out: building an export or mirroring pipeline instead — that is a separate approach, not this WK's job to
  choose.

## Open Questions

- Should we push the internal wiki repository to the public GitHub remote now?

## Checklist

- [ ] Resolve whether the wiki repository goes public before taking any action
- [ ] If yes, push the repository and record the remote URL here

## Acceptance criteria

- [ ] No push to a public remote happens before that row is filled in
