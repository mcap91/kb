# WK-0914: Send a reminder email for abandoned checkouts

## Objective

A customer who starts checkout but never finishes gets no follow-up today. Send a reminder email a fixed
interval after an abandoned checkout.

## Scope

- Detect an abandoned checkout and send one reminder email.
- Out: any change to the checkout flow itself.

## Checklist

- [ ] Add abandonment detection and the reminder email, with a test covering one abandoned checkout

## Acceptance criteria

- [ ] A checkout abandoned for the configured interval triggers exactly one reminder email, covered by a test
