# SRC-0915: Exporter upload queue retry configuration

## Summary

The nightly export job's upload step runs behind a managed queue. The queue's own retry setting is
configured separately from the job's acceptance criteria.

## Key Points

- The managed queue's retry policy is configured for 5 delivery attempts per message.
- This setting lives in the queue's own infrastructure config, not in the export job's code or spec.

## Relevance

WK-0912's acceptance criterion states the upload step retries up to 3 times. The queue the upload step
runs behind is configured for 5. This record states the queue's setting only; it does not decide whether
WK-0912's acceptance criterion should change.
