# IN-0901: Notification delivery: move from the sync adapter to the event-bus adapter

## Summary

Notification delivery currently runs through a synchronous adapter that calls each downstream channel in-line.
The event-bus adapter is the planned replacement: it publishes one event per notification and lets each
channel subscribe independently. The sync adapter stays live as the interim path until the event-bus adapter
is proven.

## Goals

- Land the event-bus adapter without a gap in delivery.
- Retire the sync adapter only after the event-bus adapter carries production traffic.

## Rulings

1. **Keep the sync adapter until the event-bus adapter lands (operator, 2026-08-10).** The sync adapter is the
   only delivery path today; removing it before the event-bus adapter is proven in production would drop
   notifications. This ruling stands until the event-bus adapter has carried production traffic and a
   follow-up ruling retires the sync adapter explicitly.
