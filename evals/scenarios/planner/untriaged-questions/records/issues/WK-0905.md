# WK-0905: Scope the nightly export job

## Objective

Stand up the nightly export job that ships each connector's output to the downstream warehouse. The job
arrives with four open questions that need settling before the build starts.

## Scope

- The job runs once per connector per night and writes one output file per run.
- Out: anything about a connector's own stage list ([[WK-0902]]'s concern, not this one).

## Open Questions

- Should the export job retry on a transient failure?
- Should export output filenames include a timestamp?
- Should the export job run on a fixed schedule or on demand only?
- Should an export failure page on-call or just log?

## Checklist

- [ ] Walk each open question against existing rulings before asking the operator
- [ ] Build the job once every question above is settled

## Acceptance criteria

- [ ] The nightly export job runs end to end for one connector in a test
- [ ] Every open question above has a `## Resolutions` row, each citing the record that settles it
