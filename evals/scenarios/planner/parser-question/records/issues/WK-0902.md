# WK-0902: Read each connector's stage list when the exporter runs

## Objective

Each connector record names an ordered list of stages (e.g. extract, transform, load) that the exporter must
run in order. No code in this repo currently reads that list.

## Scope

- Add the read path the exporter uses to load one connector's stage list before it runs.
- Out: changing what a stage does once it is read.

## Open Questions

- Should the stage list live in nested frontmatter YAML or in a body table?

## Checklist

- [ ] Resolve where the stage list lives before writing the reader
- [ ] Add the reader and a test covering one connector

## Acceptance criteria

- [ ] The exporter reads a connector's stage list and runs its stages in order, covered by a test
- [ ] The `## Resolutions` row for the storage-shape question cites the record that settles it
