# IN-0907: Exporter connector pipeline

## Summary

Each connector feeding the exporter carries its own configuration and an ordered list of stages. This
initiative tracks the work to make the exporter read and run that configuration correctly.

## Goals

- The exporter runs every connector's stages in the order the connector declares.
