# WK-0901: Wire billing to read account balances from ledger

## Objective

Billing needs the current account balance before it issues an invoice. The ledger module already computes and
owns that balance, and both modules live in this repo.

## Scope

- Billing calls into ledger to read a balance for one account id.
- No change to how ledger computes or stores the balance.
- Out: any change to ledger's public shape beyond the one read path billing needs.

## Open Questions

- Should billing reach ledger through an MCP server or a direct import?

## Checklist

- [ ] Resolve the integration shape before writing the call
- [ ] Add the read path and a test covering one account id

## Acceptance criteria

- [ ] Billing can read an account's current balance from ledger, covered by a test
- [ ] The `## Resolutions` row for the integration-shape question cites the record that settles it
